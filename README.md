# ★ PERSONA 5 ROYAL // FERREL — PORTFOLIO ★

> *"Take Your Time. The Phantom Developer has arrived to craft code that steals hearts."*

A cinematic, interactive game-console developer portfolio inspired by the iconic UI of **Persona 5 Royal (ATLUS / SEGA)**. Built with React 18, TypeScript, Tailwind CSS, and native Web Audio API.

---

## ⚡ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) + [Vite 6](https://vite.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + [shadcn/ui](https://ui.shadcn.com/)
- **Audio & FX**: Native Web Audio API + HTML5 Video Backgrounds
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

```bash
# 1. Clone repository
git clone https://github.com/FerrelHD/Persona.git
cd Persona

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Build for production:
```bash
npm run build
npm run preview
```

## 🎮 Key Highlights

- **Console Interface**: 100vw × 100vh canvas with zero scrollbars, navigable via keyboard & mouse.
- **Dynamic Backgrounds**: 1080p character loop videos (Joker, Makoto, Shinji, Fuuka) & Tokyo Leblanc Hideout.
- **Audio Synthesis**: Procedural Web Audio SFX engine + background retro music player.
- **Interactive Dossiers**: Missions showcase, tactical skill audits, and custom Calling Card studio.
