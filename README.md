# 🌙 PERSONA 3 RELOAD // FERREL — PORTFOLIO

A cinematic, interactive developer portfolio inspired by the stylized UI of **Persona 3 Reload (ATLUS / SEGA)**. Built with React 18, TypeScript, Tailwind CSS, and Web Audio API.

---

## ✨ Features

- **P3R Main Menu**: Cinematic video background loop, slanted typography, authentic Rodin fonts, and custom P3R sound effects.
- **SEES Hideout (Paulownia Mall Atrium)**: Interactive hideout featuring SEES characters (Makoto, Yukari, Junpei, Mitsuru, Fuuka, Aigis), dynamic camera focus, tech stack dossiers, and aligned central fountain water layer.
- **Authentic P3 Dialogue System**: Custom dialogue chat bubbles with dynamic character quotes and animated text typing.
- **Diagonal Slash Wipe Transitions**: 700ms electric cyan laser-blade screen transitions between menus and sub-screens.
- **Controller HUD & Custom Cursor**: Interactive PlayStation-style controller button prompts (✕, ○, △, ▢) and custom animated Persona cursor.
- **In-App Calibrators**: Live interactive position calibrators for both menu buttons and stage characters (Hotkey: `~` or `Shift + C`).

---

## ⚡ Tech Stack

- **Frontend**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) + [Vite 6](https://vite.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + Custom CSS Animations
- **Audio**: Web Audio API + Persona Sound Effects
- **Icons**: [Lucide React](https://lucide.dev/) + Custom SVG Game Vectors
- **Deployment**: [Vercel](https://vercel.com/)

## 🚀 Getting Started

### 1. Clone & Install
```bash
git clone https://github.com/FerrelHD/Persona.git
cd Persona
npm install
```

### 2. Development
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Production Build
```bash
npm run build
npm run preview
```

## 🎮 Shortcuts & Controls

- <kbd>ESC</kbd> / <kbd>Backspace</kbd> : Back to previous screen / close popup
- <kbd>`</kbd> (Backtick / Tilde) : Toggle Menu Position Calibrator
- <kbd>Shift</kbd> + <kbd>C</kbd> : Toggle Hideout Character Calibrator
